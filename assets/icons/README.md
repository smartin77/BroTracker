# Warning icon provenance

font-preview-warning.svg is original simple geometric artwork by BroTracker
contributors, created 2026-11-04 for the isolated warning composition. It was not
copied from a third-party icon set or traced from the user's screenshot.
License: GPL-3.0-or-later; the repository LICENSE contains the complete terms.

The user's reference supplies composition guidance. This SVG supplies one native
64x64 warning symbol. tools/font_preview/rasterize_icon.py converts its deliberately
restricted polygon/rounded-rect/circle subset at build time using pixel-center
sampling, with no scaling or antialiasing. The output is a palette header compiled
only into the preview. No production SVG subsystem or runtime SVG loader is added.
