# BroTracker Project Goals

BroTracker aims to become a modern, hardware-oriented music tracker that combines the classic tracker workflow with deterministic realtime playback and modular architecture.

The long-term goals of the project are:

- Deterministic playback for audio, MIDI and synchronization.
- Low-latency hardware-oriented sequencing.
- Reliable sample playback as the first playback engine.
- Modular engine architecture allowing future playback engines (FM, wavetable, synthesis, etc.).
- Clean separation between realtime engine and user interface.
- Portable and maintainable codebase.
- MOD/XM import and compatibility where practical.
- Open-source community-driven development.

BroTracker prioritizes a solid foundation over rapid feature growth.

Every development milestone should produce a usable and testable system.
